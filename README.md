# Full Stack Developer Portfolio

A polished, responsive personal portfolio for a Full Stack Web Developer built with React, Vite, Tailwind CSS, Framer Motion, and React Icons.

## Features

- Responsive layout for mobile, tablet, and desktop
- Dark and light mode with persisted preference
- Sticky glassmorphism navigation
- Smooth scrolling and scroll reveal animations
- Hero, about, skills, services, projects, experience, education, certifications, testimonials, contact, and footer sections
- Responsive testimonial slider
- Scroll-to-top actions
- Local generated portfolio images and downloadable CV
- SEO-friendly HTML metadata and semantic section structure

## Tech Stack

- React.js + Vite
- Tailwind CSS
- Framer Motion
- React Icons
- React Router

## Folder Structure

```text
src/

```

## Setup

Install dependencies:

```bash
npm install
```

Generate the local portfolio assets:

```bash
npm run generate:assets
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Customization

Edit `src/data/portfolio.js` to update your name, contact details, skills, services, projects, testimonials, education, certifications, and timeline entries.
